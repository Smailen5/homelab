# portfolio

## Ruolo

API REST del portfolio: backend Express + TypeScript + MongoDB.

## Servizi

- API con auth JWT + x-api-key
- Sync automatica progetti da GitHub (oraria)
- Conversione immagini WebP

## Note

- Progetto: `~/server-portfolio`
- Rotte principali: GET /api/projects · PUT /api/projects/:id · PUT /api/github/sync
