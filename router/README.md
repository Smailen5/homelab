# router

## Ruolo

Router/gateway della rete locale (FritzBox) con uplink ISP tramite antenna Eolo.

## Servizi

- **DHCP** - assegnazione degli indirizzi LAN (intervallo dinamico e riserve statiche)
- **Routing** - gateway della rete locale
- **Pannello web** - gestione e configurazione del dispositivo

## Sicurezza

- Esposto esclusivamente in rete locale
- Accesso protetto da credenziali (nel vault)

## Note

- Parte dell'infrastruttura di rete, documentata in `docs/mappa-lan.md`
